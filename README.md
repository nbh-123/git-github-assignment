# git-github-assignment
This is my github assignment repository


In this assignment, I learned how to create a repository with a text file, and alter this text file in different ways. One way was using the git bash and submitting a push to github. Another was utilizing different branches to edit the file. Finally, I invited another user to my repository and they edited the file, submitted a pull request on a new branch and merged their branch into main.

One challenge I faced was when I tried to push the git bash edits to github. As a security measure, I had to create a passkey and I ran into a lot of trouble on my own. I resolved this problem with the help of Dr. ElSaid kindly assisting me in creating a passkey.
